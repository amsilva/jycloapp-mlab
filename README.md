# Jyclo App 🦎
##  tracking your fasting cycles 

Um PWA (planejado) minimalista para ajudar praticantes de jejum intermitente a controlar seus checkpoints alimentares e acompanhar janelas de jejum.

### Funcionalidades (v1)

    - Acompanhamento de janelas de jejum em andamento
    - Registro de checkpoints alimentares (quando o jejum é quebrado)
    - Contador de ciclos completados
    - Visualização simples do progresso

### Principais tecnologias

    PWA (Progressive Web App)
    Frontend com HTML/CSS/JavaScript puro (minimalista)
    Backend com FastAPI, com Uvicorn
    Persistencia de dados Sqlite3
